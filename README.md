# Viewer 0.1.4

Нативный просмотрщик для Windows 11 x64: изображения, папки, ZIP/ZIP64, RAR4/RAR5 и 7z, включая solid и многотомные архивы. C++20, Win32, Direct2D/DirectWrite, libjpeg-turbo, WIC, libwebp и полная 7z.dll. Интерфейс на русском, установка приложения не требуется.

[Скачать portable-сборку для Windows x64](https://github.com/Denborodin/viewer/releases/latest) — распакуйте архив целиком и запустите `Viewer/Viewer.exe`. Исходники с архивами закреплённых зависимостей и SHA-256 также приложены к релизу. При сборке из Git зависимости загружает `tools/bootstrap.ps1`.

Запуск: `dist/Viewer/Viewer.exe`. Рядом должны оставаться `7z.dll`, `turbojpeg.dll` и файлы portable-папки. Поддерживаются PSD (сведённое изображение), JPEG, PNG, WebP, BMP, первый кадр GIF/WebP-анимации и первая страница TIFF. Учитываются EXIF, прозрачность и встроенный ICC-профиль с преобразованием в sRGB.

## Управление

Перетащите один файл, архив или папку в окно. Ctrl+O открывает диалог; правый щелчок — меню всех команд, включая открытие папки. В архиве показываются изображения из всех подпапок с естественной сортировкой полных путей; обычные папки просматриваются без рекурсии.

| Действие | Клавиши |
|---|---|
| Листание изображений | Стрелки, пробел, колесо |
| Предыдущий / следующий архив в текущей папке | Page Up / Page Down |
| Дерево файлов / обновить дерево | F9 / F5 |
| Первая / последняя картинка | Home / End |
| Масштаб относительно курсора | Ctrl+колесо |
| Перемещение | Перетаскивание изображения |
| Вписать / 100% | F / 1 |
| Поворот | R |
| Полный экран | F11, двойной щелчок; Esc — выход |
| Миниатюры | Tab |
| Добавить / удалить закладку | Ctrl+B |
| Отменить загрузку вне полного экрана | Esc |

Закладки открываются кнопкой «Закладки». Последняя позиция сохраняется автоматически. Положение, размер и развёрнутое состояние окна восстанавливаются при следующем запуске; после выхода из полноэкранного режима сохраняется геометрия обычного окна. Поворот не изменяет исходный файл. Пароли и вложенные архивы, редактирование и воспроизведение анимации не поддерживаются.

Многотомные архивы: `.part1.rar / .part2.rar`, `.rar / .r00`, `.7z.001 / .002`, `.zip.001 / .002` и `.z01 / .z02 / .zip`. Держите все части в одной папке и сохраняйте исходные имена; открыть можно также последующую часть. Томами Viewer пользуется напрямую, без объединения на диск и полной распаковки. В дереве и при Page Up/Page Down каждый набор представлен одним архивом. Подробнее: [многотомные архивы и 7z](docs/multipart.md).

## Сборка и тесты

Нужны Visual Studio Build Tools 2022 с Desktop development with C++, Windows SDK, CMake 3.25+, PowerShell 7 и установленный 7-Zip. Регистрация меню использует встроенный Windows PowerShell 5.1. Проверено: MSVC 19.44, SDK 10.0.26100.0, CMake 4.4.2. Зависимости закреплены версиями и SHA-256 в `third_party/dependencies.json`; bootstrap проверяет хеши до распаковки. Исходная поставка содержит скачанные архивы этих зависимостей.

```powershell
./tools/bootstrap.ps1
./tools/cmake.ps1 --preset windows-x64
./tools/cmake.ps1 -CmakeArguments @('--build','--preset','release','--parallel','6')
./tests/make-fixtures.ps1
ctest --preset release
cmake --install build --config Release
./tools/package.ps1
./tools/distribute.ps1
```

Обёртка `tools/cmake.ps1` нормализует дубликаты `PATH`/`Path`, которые некоторые Windows-хосты передают MSBuild. Обычные команды `cmake --preset windows-x64` и `cmake --build --preset release` также подходят при корректном окружении. Для Debug есть preset `debug`.

Небольшие RAR-файлы для тестов включены в исходники. Для их пересоздания и расширенной проверки нужен отдельно предоставленный RAR 6.x с поддержкой RAR4; генератор архивов не входит в поставку.

```powershell
./tests/make-fixtures.ps1 -RarExe 'C:\path\to\Rar.exe' -Benchmark
./tests/make-large-rar.ps1 -RarExe 'C:\path\to\Rar.exe'
ctest --preset release
./tests/performance.ps1 -Runs 20
```

`-Benchmark` создаёт два ZIP примерно по 1,7 ГБ. Большие RAR-тесты обнаруживаются автоматически, если созданы. Повторение сборки воспроизводит состав и версии; побайтовая идентичность подписанных MSIX не заявляется.

## Интеграция с Проводником

В настройках: «Включить», «Отключить», «Восстановить» и состояние регистрации. Команда «Открыть в Viewer» объявлена для основного меню Windows 11 через `IExplorerCommand` и пакет с внешним расположением файлов. Поддерживается ровно один архив, изображение или папка; DLL проверяет только имя и атрибуты объекта. Распаковка, WIC и SQLite в расширение не входят.

```powershell
./dist/Viewer/Viewer.exe --register-shell
./dist/Viewer/Viewer.exe --unregister-shell
```

Первая локальная поставка содержит подписанный тестовым сертификатом `integration/Viewer.msix` и только публичный `Viewer.Local.cer`. Закрытый неэкспортируемый ключ хранится в личном хранилище сертификатов Windows, вне исходников и поставки. GUI явно предупреждает об импорте публичного сертификата в TrustedPeople текущего пользователя.

**Особенность локальной подписи:** проверенная Windows 11 25H2 не принимает доверие MSIX только из хранилища текущего пользователя (0x800B0109). Поэтому при уже включённом пользователем режиме разработчика применяется регистрация манифеста через `Add-AppxPackage -Register -ExternalLocation`; состояние показывает `Development`. Добавленный во время неудачной попытки сертификат удаляется из TrustedPeople. Viewer не включает режим разработчика, не изменяет доверие на уровне компьютера и не перезапускает Проводник. Если Developer Mode выключен, локальная интеграция требует доверенной подписи; обычный просмотр работает без регистрации.

Для публичной поставки нужны сертификат доверенного издателя, соответствующие Publisher в обоих манифестах и подпись MSIX. Получение такого сертификата в эту сборку не входит. Подробности: [регистрация меню Microsoft](https://learn.microsoft.com/en-us/windows/apps/desktop/modernize/integrate-packaged-app-with-file-explorer), [проверка доверия MSIX](https://learn.microsoft.com/en-us/windows/msix/msix-troubleshooting-guide).

Регистрация выполняется для текущего пользователя и не меняет стандартные ассоциации. После переноса portable-папки нажмите «Восстановить». Перед удалением папки отключите интеграцию. Если меню не обновилось, повторно войдите в Windows. Тест регистрации/переноса: `tests/shell-integration.ps1` в Windows PowerShell 5.1; он оставляет интеграцию включённой для `dist/Viewer`.

## Кеш, ограничения и диагностика

Данные: `%LOCALAPPDATA%/Viewer`. Лимиты по умолчанию: RAM 512 МиБ, но не более 1/8 физической памяти; текстуры GPU 256 МиБ; диск 2 ГиБ. RAM ограничивает управляемые кеши, а не весь процесс: словарь архиватора и временная память WIC учитываются отдельно. Настройки позволяют изменить три лимита и очистить кеш. `VIEWER_DATA_DIR` изолирует данные тестового запуска.

На диск записываются извлечённые байты по мере обращения. Файлы старше семи дней и давно использованные элементы вытесняются; изменение файла источника меняет ключ кеша. При недоступном диске просмотр продолжается с RAM-кешем. Изображения не сохраняются по внутренним путям архива.

Из ZIP и несолидного RAR извлекаются запрошенные элементы. В solid RAR рабочий поток приостанавливается внутри одного `Extract`, сохраняя словарь; движение вперёд продолжает сессию, возврат использует кеш. При промахе кеша или переходе в другой блок сессия начинается заново. Дальний первый переход и отличие физического порядка файлов от естественной сортировки могут требовать обработки предшествующих данных — ограничение solid-формата.

Разрешение декодирования растёт при увеличении масштаба. GPU получает изображение частями до 4096 пикселей. При превышении бюджета пикселей разрешение ограничивается: произвольно большое изображение не гарантированно доступно в полном 1:1. Один исходный элемент ограничен 512 МиБ (и 1/16 физической памяти для архива), изображение — миллиардом пикселей; словарь архиватора — 1 ГиБ и 1/4 памяти.

```powershell
./dist/Viewer/ViewerBench.exe ./tests/fixtures/generated/stored.zip 20
./dist/Viewer/Viewer.exe ./tests/fixtures/generated/stored.zip --test-output ./build/smoke
```

`--test-output` — режим разработчика: сохраняет `window.png`, счётчики извлечения и время первого рендера, затем закрывает окно. Приложение с зарегистрированной package identity нужно тестировать в обычном пользовательском сеансе; изолированный процесс может не иметь доступа к регистрации.

Результаты и непроверенные пункты: `docs/validation.md`; архитектура: `docs/architecture.md`. Лицензии и исходники зависимостей сопровождают поставку; 7z.dll можно заменить совместимой сборкой.

PSD: RGB/Grayscale 8/16 бит и Indexed 8 бит, Raw/RLE/ZIP, прозрачность и ICC. Ограничения и проверки: [docs/psd.md](docs/psd.md).

Панель «Файлы» показывает папки, ZIP/RAR/7z и поддерживаемые изображения. Подпапки загружаются при раскрытии, «На уровень выше» меняет корень дерева. Открытый архив раскрывается во внутренние папки: выбор папки показывает её первое изображение, выбор файла — этот файл. Дерево строится по каталогу без дополнительной распаковки; лента миниатюр включает изображения всех вложенных папок. Page Up/Page Down переключают архивы текущей папки в естественном порядке, без перехода по кругу. В полном экране дерево скрывается. Подробнее: [docs/file-tree.md](docs/file-tree.md).
