# Многотомные архивы и 7z — 0.1.4

Поддерживаются обычный и solid 7z, RAR4/RAR5 с именами `book.part1.rar`, `book.part2.rar` (включая ведущие нули), старые наборы `book.rar`, `book.r00`, `book.r01`, нумерованные `book.7z.001` / `.002` и `book.zip.001` / `.002`, дисковые ZIP `book.z01`, `book.z02`, …, `book.zip`.

Все части должны находиться рядом и сохранять исходные имена. При выборе последующей части Viewer переходит к начальной; для дискового ZIP каталог находится в конечном `.zip`. Общая точка открытия используется для дерева, закладок и последней позиции. Файловое дерево показывает набор один раз; Page Up/Page Down пропускают отдельные части. Диалог, перетаскивание, командная строка и расширение Проводника распознают новые расширения. Для уже загруженной старой DLL Проводника может потребоваться новый вход в Windows; приложение не завершает Проводник автоматически.

RAR и дисковые ZIP получают соседние потоки через `IArchiveOpenVolumeCallback`. Имена из архива ограничены файлами в той же папке: абсолютные пути, переходы по каталогам и альтернативные потоки не принимаются. Нумерованные 7z/ZIP используют виртуальный seekable-поток: смещения отображаются на части, читается нужный диапазон; объединённый временный файл не создаётся. Каталог не извлекает изображения. Для solid 7z используются номера блоков `kpidBlock`, чтение вперёд продолжается в одном вызове `Extract`, как для solid RAR.

Отсутствующий начальный/промежуточный/конечный том приводит к ошибке открытия. Когда обработчик сообщает имя отсутствующей части, оно включается в сообщение; иначе показывается общая ошибка повреждения/отсутствующего тома. Пароли и архивы внутри архивов не поддерживаются. Первый дальний переход в solid-блок требует декодирования предшествующих данных. Ключ кеша включает метаданные всех обнаруженных частей, поэтому изменение любого тома инвалидирует сохранённые изображения.

Проверки: точное сравнение изображения, пересекающего границы частей, для RAR4/RAR5, legacy RAR, split 7z/ZIP и дискового ZIP; открытие последующей части; отсутствие извлечения при чтении каталога; один `Extract` для последовательных изображений solid 7z и solid multipart RAR; отмена и закрытие; отсутствующие тома; смена ключа кеша после изменения сопровождающей части; фильтрация дерева, переключение архивов, реальный кадр в окне и состояния `IExplorerCommand`.

`tests/make-fixtures.ps1` вызывает `tests/multipart-fixtures.ps1`: 7-Zip создаёт 7z и нумерованные части, отдельный генератор выставляет поля дисков ZIP. Малые RAR-fixtures включены в исходную поставку. Новые RAR4-наборы созданы RAR 6.24 с `-ma4 -m0 -ep1 -v256k` (для legacy дополнительно `-vn`), solid RAR5 — с `-ma5 -m1 -s -ep1 -v10k`. Генератор RAR не входит в поставку.
