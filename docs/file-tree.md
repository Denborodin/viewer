# Дерево файлов и переход между архивами — 0.1.5

Слева добавлен нативный Win32 TreeView с папками, ZIP/RAR/7z и поддерживаемыми изображениями. Кнопка «Файлы» или F9 скрывает/показывает панель; настройка сохраняется. F5 обновляет дерево. Полный путь доступен во всплывающей подсказке. «На уровень выше» меняет корневую папку; другой диск можно выбрать через открытие папки.

Выбор изображения или архива открывает его. Выбор папки на диске открывает изображения этой папки; раскрытие стрелкой подгружает её содержимое. Чтение папок выполняется отдельным рабочим потоком, без рекурсивного предварительного обхода.

Открытый ZIP, RAR или 7z раскрывается в дерево внутренних папок и изображений. Иерархия строится из уже прочитанного каталога: дополнительной распаковки для списка нет. Узлы вложенных папок добавляются при раскрытии; выбор внутренней папки показывает её первое изображение, выбор файла — соответствующее изображение в текущей сессии архива. Папки идут перед файлами, имена сортируются естественно. Поддерживаются Unicode, несколько уровней вложенности, разделители `/` и `\\`, одинаковые имена файлов. При листании дерево выделяет текущий файл и раскрывает его родителей; F5 восстанавливает выбранный внутренний файл. При переходе к другому архиву старые внутренние узлы удаляются.

Лента миниатюр показывает все изображения архива, включая вложенные папки; выбор в дереве синхронизирует текущую позицию просмотра. Пустые папки и папки без поддерживаемых изображений не показываются. Вложенные ZIP/7z/RAR показываются как выбираемые галереи; Enter открывает выделенную галерею, Backspace возвращает к внешнему архиву. Внутри галереи Page Up/Page Down переключают соседние вложенные архивы. Подробности: [nested-archives.md](nested-archives.md).

Page Up / Page Down переходят к предыдущему/следующему ZIP, RAR или 7z в той же папке в естественном порядке: `1.zip`, `2.rar`, `10.zip`. Перехода по кругу нет. Из папки или обычного изображения Page Down открывает первый архив, Page Up — последний. Клавиши работают и при фокусе дерева. При открытии архива восстанавливается последняя просмотренная позиция, как и при обычном открытии. Стрелки, пробел и колесо в области просмотра продолжают листать изображения; внутри дерева стрелки управляют самим деревом, колесо прокручивает список.

В полном экране дерево скрывается и возвращается при выходе. Панель миниатюр работает рядом с деревом. Раскрытие папок не сохраняется между запусками. Изменения файловой системы отображаются после F5; автоматического наблюдения за папкой нет.

Проверено: пять наборов CTest, включая фильтрацию списка, Unicode, естественный порядок архивов разных форматов, границы без зацикливания, накопление нескольких шагов, отмену чтения папки, Page Up/Page Down с фокусом дерева и просмотрщика, раскрытие подпапок и закрытие во время работы. Тесты внутренних папок проверяют естественный порядок, одинаковые имена, оба разделителя, выбор первого изображения папки, обновление F5, очистку устаревших узлов и повторное открытие. Интеграционный тест с настоящим ZIP проверяет обновление кадра при выборе вложенного изображения без смены сессии архива. Снимок реального TreeView проверен визуально.
