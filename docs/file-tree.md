# Дерево файлов и переход между архивами — 0.1.2

Слева добавлен нативный Win32 TreeView с папками, ZIP/RAR и поддерживаемыми изображениями. Кнопка «Файлы» или F9 скрывает/показывает панель; настройка сохраняется. F5 обновляет дерево. Полный путь доступен во всплывающей подсказке. «На уровень выше» меняет корневую папку; другой диск можно выбрать через открытие папки.

Выбор изображения или архива открывает его. Выбор папки открывает изображения этой папки; раскрытие стрелкой подгружает её содержимое. Просмотр изображений внутри архива остаётся в ленте миниатюр: файловое дерево не распаковывает архивы для построения списка. Чтение папок выполняется отдельным рабочим потоком, без рекурсивного предварительного обхода.

Page Up / Page Down переходят к предыдущему/следующему ZIP или RAR в той же папке в естественном порядке: `1.zip`, `2.rar`, `10.zip`. Перехода по кругу нет. Из папки или обычного изображения Page Down открывает первый архив, Page Up — последний. Клавиши работают и при фокусе дерева. При открытии архива восстанавливается последняя просмотренная позиция, как и при обычном открытии. Стрелки, пробел и колесо в области просмотра продолжают листать изображения; внутри дерева стрелки управляют самим деревом, колесо прокручивает список.

В полном экране дерево скрывается и возвращается при выходе. Панель миниатюр работает рядом с деревом. Раскрытие папок не сохраняется между запусками. Изменения файловой системы отображаются после F5; автоматического наблюдения за папкой нет.

Проверено: пять наборов CTest, включая фильтрацию списка, Unicode, естественный порядок архивов разных форматов, границы без зацикливания, накопление нескольких шагов, отмену чтения папки, Page Up/Page Down с фокусом дерева и просмотрщика, выделение текущего архива, раскрытие подпапок и закрытие во время работы. Снимок реального TreeView проверен визуально. Пример-изображение интерфейса в запросе отсутствовало, поэтому использована компактная стандартная древовидная панель.
