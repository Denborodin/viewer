# Просмотр PSD

PSD открывается из файла, папки, ZIP и RAR, через диалог, перетаскивание, командную строку и команду «Открыть в Viewer». Миниатюры, предзагрузка, масштаб и закладки используют общий конвейер.

Поддерживаются сведённые изображения PSD версии 1:

* RGB и Grayscale с глубиной 8/16 бит; вывод на экран — 8 бит на канал.
* Indexed 8 бит, включая индекс прозрачности.
* Raw, PackBits RLE, ZIP и ZIP с предсказанием.
* Прозрачность сведённого изображения, RGB/Gray ICC с преобразованием в sRGB. Сохранённый дополнительный альфа-канал без признака прозрачности не скрывает изображение.

Данные слоёв не декодируются и не сводятся заново. Требуется сохранённое сведённое изображение: в Photoshop включите максимальную совместимость PSD. PSB, CMYK, Lab, Multichannel, Bitmap 1 бит и HDR 32 бит пока не поддерживаются; приложение сообщает об этом явно.

Декодирование выполняется построчно с уменьшением под окно и проверкой отмены между строками. Полноразмерные распакованные плоскости каналов в RAM не создаются. Из исходного PSD общий источник пока читает весь файл, включая байты слоёв; это не выборочное дисковое чтение. Действует общий лимит размера исходных байтов и декодированного кадра. При уменьшении используется усреднение групп пикселей.

## Проверка

273 автоматические проверки PSD: варианты глубины/режима/сжатия, эталонные пиксели, уменьшение, прозрачность и белая подложка, сохранённый альфа-канал, индекс прозрачности, sRGB ICC, повреждённые/усечённые данные, ZIP checksum, PackBits, отсутствие composite, отмена и бюджет. Проверка расширения Проводника включает PSD и не читает содержимое файла.

```powershell
ctest --preset release
./tests/psd-archives.ps1
# Дополнительно, если установлен генератор RAR:
./tests/psd-archives.ps1 -RarExe 'C:\Program Files\WinRAR\Rar.exe'
```

Дополнительно проверены пять независимых файлов из [psd-tools](https://github.com/psd-tools/psd-tools/tree/8f9a25ea98202061365701db54ce938931b27c09/tests/psd_files): `1layer.psd`, `2layers.psd`, `16bit5x5.psd`, `gray0.psd`, `transparentbg-gimp.psd`. Они не включены в поставку. Результат сравнивался с `PSDImage.topil()` из psd-tools 1.20.0 после приведения к premultiplied BGRA: RGB и прозрачный GIMP-файл совпадают точно; максимальная разница для 16 бит — 1/255, для Gray ICC — 4/255 (средняя 0,106/255). Photoshop при проверке не запускался.

Парсер реализован по [спецификации Adobe](https://www.adobe.com/devnet-apps/photoshop/fileformatashtml/). ZIP распаковывается статически связанной zlib 1.3.2; версия, источник и SHA-256 закреплены в `third_party/dependencies.json`. Новых DLL для PSD не требуется.
