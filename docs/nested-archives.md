# Вложенные галереи — 0.1.5

Поддерживается сценарий `collection.7z.001` → `galleries/album.zip` → изображения. Внешний архив может быть многотомным. В каталоге показываются вложенные ZIP, 7z и отдельные RAR; их содержимое не извлекается при построении списка или миниатюр.

Выберите галерею в дереве или нажмите Enter на выделенном архиве. Выбранный внутренний архив целиком извлекается во временный файл, после чего изображения читаются адресно обычным обработчиком. Остальные галереи не извлекаются. Для solid внешнего архива обработчик может декодировать предшествующие данные блока — это ограничение формата.

Backspace или пункт «Назад к внешнему архиву» возвращает к списку галерей. Page Up/Page Down внутри галереи переключает соседние вложенные архивы в естественном порядке, без перехода по кругу. В корне эти клавиши продолжают переключать физические архивы. Стрелки и колесо в области изображения листают картинки. Заголовок показывает цепочку архивов, дерево — текущую галерею и её внутренние папки.

Закладки содержат устойчивые адреса по ID элементов, а не пути временных файлов; повторное открытие закладки снова извлекает нужную галерею. Последняя позиция внутри галереи восстанавливается при её открытии. Изменение внешнего архива/его частей меняет ключ кеша. Повторное открытие внутреннего архива может снова потребовать его извлечения; временный файл не является постоянным кешем.

Временные файлы находятся в `%LOCALAPPDATA%/Viewer/nested`, получают случайные имена и создаются с Windows `FILE_FLAG_DELETE_ON_CLOSE`. Они удаляются при закрытии галереи, ошибке, отмене или завершении процесса. Внутренние пути архива не используются как пути распаковки. Операции выполняются вне потока интерфейса; Esc отменяет открытие, после ошибки прежний каталог остаётся доступен.

Ограничения: до трёх уровней вложенности; один внутренний архив — до 2 ГиБ; требуется свободное место на диске для временного файла. Эти рабочие файлы не входят в настраиваемый постоянный дисковый кеш. Во время перехода могут одновременно существовать старый и новый временные архивы, а при нескольких уровнях — промежуточные. Пароли и многотомные наборы *внутри* архива не поддерживаются; многотомный внешний контейнер поддерживается.

Проверены: ZIP-галереи и внутренний 7z в multipart 7z, чтение и декодирование изображений, отсутствие извлечения других галерей, возврат к внешнему каталогу, Page Up/Page Down, повторное открытие виртуального адреса, стабильный ключ кеша, повреждённая галерея и восстановление навигации, отмена во время записи временного файла и его очистка. Снимки нативного дерева и подготовленного кадра проверены визуально. Общий прогон: пять наборов CTest.
